### Comandos del flujo diario entre Mac y Windows

Guarda este resumen como tu plantilla de trabajo:

| Momento | Comando en Mac / Warp | Comando en Windows (CMD / PowerShell) | Propósito |
| --- | --- | --- | --- |
| **Al llegar (antes de tocar código)** | `git pull origin main` | `git pull origin main` | Descarga lo que hiciste en la otra PC |
| **Al terminar de programar (Paso 1)** | `git add .` | `git add .` | Selecciona todos los archivos modificados |
| **Al terminar de programar (Paso 2)** | `git commit -m "mensaje"` | `git commit -m "mensaje"` | Empaqueta los cambios con una descripción |
| **Al terminar de programar (Paso 3)** | `git push origin main` | `git push origin main` | Sube los cambios a GitHub |
