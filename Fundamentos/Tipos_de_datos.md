### Tipos de datos en C++
Una variable en C++ debe ser un tipo de datos especificado:

## Data Type	Size	Description

1. bool	1 byte	Stores true or false values

2. char	1 byte	Stores a single character/letter/number, or ASCII values

3. int	2 or 4 bytes	Stores whole numbers, without decimals

4. float	4 bytes	Stores fractional numbers, containing one or more decimals. Sufficient for storing 6-7 decimal digits

5. double	8 bytes	Stores fractional numbers, containing one or more decimals. Sufficient for storing 15 decimal digits


```cpp
Ejemplo

int myNum = 5;               // Integer (whole number)
float myFloatNum = 5.99;     // Floating point number
double myDoubleNum = 9.98;   // Floating point number
char myLetter = 'D';         // Character
bool myBoolean = true;       // Boolean
string myText = "Hello";     // String
```
